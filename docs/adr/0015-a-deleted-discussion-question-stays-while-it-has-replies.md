# A deleted Discussion Question stays while it has replies

When a Discussion Question is deleted, the Lesson page keeps showing it, marked as deleted, for as long as it still has Discussion Replies, so the replies keep the question they answer. Once no replies are left, the deleted Discussion Question is hidden: it has nothing worth showing. A deleted Discussion Reply is always hidden, because nothing hangs off it (replies are one level deep).

## Considered Options

- **Hide a deleted Discussion Question at once, with its replies**: rejected, because it throws away answers other Students may still need.
- **Always show deleted Discussion Questions as a placeholder**: rejected, because a placeholder with no replies under it is noise.
